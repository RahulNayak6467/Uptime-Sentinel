# V18 — Production Monitoring and Dogfooding

> Part of the [StatusForge roadmap](../../ROADMAP.md). See the index for the full
> version map, current state, and the deferred-work register.

**Status:** Not started

### Goal and scope

Monitor StatusForge with StatusForge and add deep metrics, logs, traces, SLOs,
alerts, and operational runbooks for every major subsystem.

### Core features

- [ ] Dogfood StatusForge endpoints and alerting flows.
- [ ] Prometheus metrics for API, workers, scheduler, database, Redis, and
  business events.
- [ ] Provisioned Grafana dashboards and alert rules.
- [ ] Loki aggregation for structured logs and cross-signal investigation.
- [ ] OpenTelemetry traces across API and worker boundaries.
- [ ] SLI/SLO definitions for API uptime, check latency, and alert latency.
- [ ] Runbooks, retention policies, and an on-call incident simulation.

### Concepts learned

Counters/gauges/histograms, dashboards as code, log aggregation, distributed
tracing, SLI/SLO/SLA design, actionable alerting, runbooks, on-call practice,
and dogfooding.

### Out of scope

A commercial observability product, 24/7 staffing, and infrastructure complexity
that does not improve the learning goals.
