# V14 — Billing and Plans

> Part of the [StatusForge roadmap](../../ROADMAP.md). See the index for the full
> version map, current state, and the deferred-work register.

**Status:** Not started

### Goal and scope

Introduce Stripe subscriptions and enforce plan entitlements consistently.

### Core features

- [ ] Free, Pro, and Team limits for monitor count, interval, history, and
  workspace access.
- [ ] Stripe checkout/subscriptions and verified billing webhooks.
- [ ] Subscription state, usage metering, and entitlement middleware.
- [ ] Graceful downgrade behavior when a subscription lapses.

### Concepts learned

Stripe webhooks, signature verification, subscription state, entitlements,
usage metering, and downgrade behavior.

### Out of scope

Multiple payment providers, tax automation, invoicing platforms, and custom
enterprise contracts.
