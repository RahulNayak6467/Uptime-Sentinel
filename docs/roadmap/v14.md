# V14 — Billing and Plans

> Part of the [StatusForge roadmap](../../ROADMAP.md). See the index for the full
> version map, current state, and the deferred-work register.

**Status:** Descoped — not building. StatusForge is **single-user by design.**

> **Decision (2026-08-03):** V14 is cut. StatusForge is a single-owner learning
> project, and billing adds no reliability or correctness value to it. Every core
> item in this version exists only to sell and enforce paid plans: Stripe
> subscriptions, usage metering, and entitlement middleware all serve payment
> gating, and the "Team" plan tier plus "workspace access" limit depend on V9
> (Teams/Workspaces), which is itself descoped. Strip out payments and nothing
> substantive remains. This file is preserved (not deleted) so the scope and
> reasoning survive if the decision is ever revisited (e.g. if StatusForge is
> ever taken to market). Everything below is retained for reference only and is
> not being built.

### Goal and scope

Introduce Stripe subscriptions and enforce plan entitlements consistently.

### Core features

- [ ] Free, Pro, and Team limits for monitor count, interval, history, and
  workspace access.
- [ ] Stripe checkout/subscriptions and verified billing webhooks.
- [ ] Subscription state, usage metering, and entitlement middleware.
- [ ] Graceful downgrade behavior when a subscription lapses.

### Concepts learned

Stripe webhooks, signature verification, subscription state, entitlements,
usage metering, and downgrade behavior.

### Out of scope

Multiple payment providers, tax automation, invoicing platforms, and custom
enterprise contracts.
