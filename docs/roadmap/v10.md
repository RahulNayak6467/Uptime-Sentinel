# V10 — Security Hardening and API Versioning

> Part of the [StatusForge roadmap](../../ROADMAP.md). See the index for the full
> version map, current state, and the deferred-work register.

**Status:** Not started

### Goal and scope

Protect the monitoring service from abuse and publish a stable, documented V1
API contract.

### Core features

- [ ] SSRF protection for local/private/link-local/cloud-metadata addresses,
  including DNS resolution and redirect revalidation.
- [ ] Route-specific rate limits, Helmet, strict CORS, request-size limits, and
  outbound response-size limits.
- [ ] `/v1` route prefix, OpenAPI specification, Swagger UI, changelog, and
  deprecation policy.
- [ ] Replace Bull Board basic auth with application JWT/RBAC authorization.

### Supporting work

- [ ] IP-range utilities, redirect limits, security tests, and documented block
  rules.

### Concepts learned

SSRF and DNS rebinding risks, private networks, abuse controls, security headers,
API versioning, OpenAPI, documentation, and deprecation.

### Out of scope

Performance tuning, regional deployment, billing, and advanced threat detection.
