# V13 — Integrations

> Part of the [StatusForge roadmap](../../ROADMAP.md). See the index for the full
> version map, current state, and the deferred-work register.

**Status:** Not started

### Goal and scope

Deliver alerts through Slack, Discord, and generic signed webhooks using a
reliable, auditable channel abstraction.

### Core features

- [ ] Alert-channel CRUD and encrypted/safe configuration storage.
- [ ] Slack, Discord, and generic webhook delivery.
- [ ] Per-channel notification logs, retries, idempotency, and test delivery.
- [ ] HMAC signing for outbound webhooks and verification for supported inbound
  callbacks.

### Concepts learned

Outbound webhooks, HMAC, idempotent delivery, channel routing, retries, and
secret handling.

### Out of scope

Marketplace integrations, OAuth app directories, and billing.
