# V9 — Teams and Workspaces

> Part of the [StatusForge roadmap](../../ROADMAP.md). See the index for the full
> version map, current state, and the deferred-work register.

**Status:** Not started

### Goal and scope

Support collaborative, tenant-isolated workspaces with explicit roles and
auditable membership changes.

### Core features

- [ ] Workspaces, members, expiring invites, and workspace-owned monitors.
- [ ] Owner, admin, member, and viewer roles.
- [ ] Workspace alert settings and audit logs.
- [ ] Role-aware Bull Board access.

### Supporting work

- [ ] Central RBAC middleware and per-action permission matrix.
- [ ] Owner-protection rules, invite expiry, and multi-tenant isolation tests.

### Concepts learned

RBAC, permission matrices, many-to-many membership, invitations, audit logging,
and multi-tenant boundaries.

### Out of scope

Billing, enterprise identity, custom roles, and cross-workspace sharing.
