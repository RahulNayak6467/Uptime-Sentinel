# V0 — URL Checker Prototype

> Part of the [StatusForge roadmap](../../ROADMAP.md). See the index for the full
> version map, current state, and the deferred-work register.

**Status:** Complete

### Goal and scope

Prove the core monitoring operation: accept one public HTTP(S) URL, check it,
measure latency, and return a consistent `UP` or `DOWN` result.

### Core features

- [x] `POST /check-url` with Zod request validation.
- [x] HTTP/HTTPS URL validation and configurable timeout.
- [x] Status, status code, response time, and error message response fields.
- [x] Network, timeout, and HTTP 4xx/5xx handling. An HTTP response counts as
  `UP` even when its status code is an application error.

### Supporting work

- [x] TypeScript and environment configuration.
- [x] Route → controller → service separation.
- [x] Consistent response shapes, `AppError`, and global error middleware.

### Concepts learned

HTTP health checks, Fetch error types, `AbortSignal`, request validation,
custom errors, async error handling, and layered backend structure.

### Out of scope

Persistence, saved monitors, authentication, scheduling, queues, and frontend.
